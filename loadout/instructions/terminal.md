## My Terminal

I keep a shell in another pane of your iTerm2 tab and run commands there while we work. `term-peek` prints its recent output (`-n <lines>`, default 200). Check it before asking me or guessing when I mention something I ran or saw there, or when the project changed in a way you didn't cause: different files staged, a new commit or branch, files edited, a server stopped. If it doesn't explain the change, another agent made it. It can't run inside the nono sandbox; ask me there instead.
