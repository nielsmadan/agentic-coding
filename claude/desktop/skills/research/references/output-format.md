# Output Format

Lead with the answer. Keep it concise. Only add sections that provide value beyond the main answer.

```markdown
## {topic}

{Direct answer to the question. State the recommended approach or key finding up front. Use inline source counts for transparency — e.g., "(3 sources)" or "(1 source, low confidence)".}

**Key references:**
1. [{title}]({url}) — {why this matters}
2. [{title}]({url}) — {why this matters}
3. [{title}]({url}) — {why this matters} (only if a 3rd source significantly shaped the answer)

{STOP HERE if the answer above covers it. Only add sections below if they provide substantial additional value.}

---

**Comparison** (only for comparison queries with meaningful pros/cons to lay out)

{Option A}: {pros, cons, best for, price range}
{Option B}: {pros, cons, best for, price range}

**Regional details** (only if region-specific info wasn't already in the main answer)

{Local regulations, pricing, availability}

**Conflicting sources** (only if sources materially disagree)

{Source A} says X, {source B} says Y. Resolution: {which to trust and why}.
```

## Guidelines

- **No empty sections.** If a section would just repeat the main answer or has nothing to add, skip it entirely.
- **Inline source counts.** Use "(N sources)" or "(1 source, low confidence)" next to claims to show how well-supported they are.
- **Confidence is implicit.** Source counts + reference quality communicate confidence without needing a separate confidence block. Only call out confidence explicitly if it's notably low.
- **Shorter is better.** A 5-sentence answer with 3 good sources beats a structured report with empty sections.
