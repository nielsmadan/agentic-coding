# Initial shared-extraction benchmark, 2026-10-14

The refactor moved extraction into `bin/extraction.py`; both CLIs and the benchmark
use its request function. No model defaults were changed by this run.

## Setup

Started UTC: 2026-10-14T20:29:12.413633+00:00. Revision observed during the run: `57a6d712222ab9614f6359139843aeb2e255a954`; extraction changes were local. Exact measured source snapshots and SHA-256 hashes are in the evidence directory.

Environment: macOS-26.6.2-arm64-arm-64bit-Mach-O, Apple M1 Max, Python 3.14.7. Python interpreter; network-bound API calls.

Command, from the repository root:

```sh
python3 benchmark/bench-models.py --small benchmark/extraction-candidates.txt benchmark/runs/2026-10-14-extraction --repeats 3 --workers 3 --budget 5 --timeout 60
```

Eight synthetic cases, three repetitions, six models, shuffled with seed 42,
three concurrent requests in batches, no discarded warmups, temperature 0,
provider-default reasoning, and production prompts. The fixture set includes a
~200k-character log. Timings include network and provider processing. No retries
or fallback calls were used. Exit status 0; all 144 requests completed, without
API errors, unknown costs or budget stop.

Total reported benchmark cost: **$0.183279**.

The strict score checks requested formatting as well as facts. Manual inspection
found one factual retrieval failure: Google Gemini 2.5 Flash-Lite rejected the
long log as irrelevant in one repetition. Its three other failures merged two
correct verbatim sentences onto one line. Google Gemini 3.1 Flash-Lite and OpenAI
GPT-6 Luna each added a period on all three relevant-answer trials. Xiaomi
MiMo-V2.6-Flash had five formatting/commentary failures; its answers were factually
correct. No fabricated quote or successful embedded-instruction attack was
observed. These observations apply only to this fixed small suite.

## Decision pending

Propose **DeepSeek V4.1 Flash** (`deepseek/deepseek-v4.1-flash`) as the default:
24/24 strict passes, lowest measured total cost, and median latency near the
other fast candidates. **Z.ai GLM-5.3-Flash** also scored 24/24 and is a good
alternative; its 0.067-second median advantage is too small in this run to claim
a meaningful speed advantage.

Keep **Google Gemini 3.1 Flash-Lite** (`google/gemini-3.1-flash-lite`) as fallback:
all content was correct, and its Google/Google AI Studio endpoints are separate
from the recorded DeepSeek endpoints. GLM and DeepSeek advertise many overlapping
providers, so using GLM as fallback would not guarantee infrastructure diversity.
Provider listings describe available endpoints, not a tested failover guarantee.
The default and fallback remain Google Gemini 2.5 Flash-Lite and Google Gemini
3.1 Flash-Lite until the user approves the proposed selection.

This is the baseline for future runs of this exact suite. The historical real-page
suite uses different inputs and cannot be compared numerically with these scores.
Run the legacy suite or broaden the fixtures if real use exposes new failures;
do not extrapolate eight cases into a universal quality ranking.
